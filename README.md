# EARENDEL MUSIC

A native Android online music discovery and playback app.

## Build
The Build EARENDEL MUSIC APK workflow runs on pushes to main that touch app source, Gradle files, or the workflow. It can also be started manually from GitHub Actions. Download the EARENDEL-MUSIC-APK artifact from a successful workflow run.

## Music catalogue and rights
Search uses the Internet Archive advanced search API, filtering for records marked with a Creative Commons licence. Individual files remain hosted by Internet Archive and are streamed from their original source. Search availability and playback depend on each uploader's metadata, licence, and access status. This app does not bundle copyrighted commercial recordings.

## Current scope
- Online search for Creative Commons audio
- Bangla artist quick-search shortcuts (ASHES, Artcell, Highway, Shonar Bangla Circus); results appear only if licensed audio is available in the catalogue
- Streaming playback, favorites, and a compact now-playing control
- Dark violet EARENDEL design

This initial build does not yet include background/lock-screen media controls, queue management, or full artist and album pages.
